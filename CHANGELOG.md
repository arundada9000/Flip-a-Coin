# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-01

### Added
- Initial release

### Features
- Realistic 3D-style coin toss with smooth animations
- Multiple coins (add and toss as many as you want)
- Two toss styles (In-Place and Vertical)
- Full-screen mode
- Sound effects for flipping and landing
- Live statistics (heads, tails, total coins, total tosses)
- Responsive design for all screen sizes
- PWA support (installable, offline via service worker)

### Enhancements
- Dynamic gradient background
- Netlify hosting with robots.txt and sitemap
